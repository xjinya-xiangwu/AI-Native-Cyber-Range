# AI-Native-Cyber-Range · 前沿版演示

面向安全研究与领导演示的 AI-native 网络安全任务原型。

**推理会话 → 执行画布 / 数据管线 → 产出物卡片 → 资产空间**

## 四类典型任务

- **漏洞挖掘**：授权定界、环境基线、攻击面测绘、发现验证、研判去重、报告复测。
- **漏洞利用**：目标确认、前置核验、最小利用链、受控利用、影响边界、清理归档。
- **漏洞修复**：工单分级、隔离复现、根因分析、补丁实施、安全与业务回归、发布关闭。
- **数字孪生攻防**：规则定义、孪生同步校准、攻击注入、检测响应、韧性恢复、状态回放。

## 演示分工

- **左侧推理会话**：只呈现可审查推理摘要、观测依据和人工对话式干预；任务目标与干预输入框磁吸在会话顶部。
- **右侧执行画布**：集中显示任务建立、权限边界确认、执行编排、Milestones、靶场/三维数字孪生环境、当前动作和运行记录。
- **自动执行**：任务建立完成后自动逐步运行，无需人工点击“下一步”。权限边界在建立阶段冻结，后续自动执行遵循既定约束。
- **数据管线**：展示长轨迹、运行记录、步骤标注、分支提取、人工质检和数据封装回流。

## 资产空间

资产按两类呈现：

1. **报告产出**：验证记录、根因分析、补丁/评估报告、复测或场景报告。
2. **数据集产出**：长轨迹、评测数据、可核验运行记录和回放数据。

点击资产可打开 Trace 详情弹窗；每项支持导出 JSON。

## 安全边界

- 所有事件、指标、工具回显和结果均为固定演示数据或仿真执行。
- 所有任务限定在授权、隔离、可回滚的靶场或数字孪生环境。
- 禁止真实网络、真实账号、生产凭据、持久化和无约束破坏动作。
- 最小权限、允许动作、停止条件和留痕要求均在任务建立阶段确认并冻结。
- 页面只展示计划摘要、工具结果、观测和决策依据，不展示隐藏思维链。

## 本地运行

无需安装依赖：

```bash
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

## 推荐演示操作

1. 首页选择任一典型任务，点击“启动演示任务”。
2. 观察右侧任务建立过程如何确认权限边界、编排环境和冻结 Milestones。
3. 左侧持续阅读过程推理，随时在顶部输入框发送干预，查看右侧执行画布的同步投影。
4. 数字孪生任务中点击三维生产环境节点，查看资产状态和遥测信息。
5. 任务完成后从产出物卡片或资产空间打开 Trace 详情，并导出报告或数据集 JSON。
