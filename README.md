# AI-Native-Cyber-Range · 前沿版演示

面向安全研究与领导演示的 AI-native 网络安全任务原型。

**流式推理会话 → 执行画布 / 数据管线 → 报告与数据集 → 资产空间**

## 四类典型任务

- **漏洞挖掘**：授权定界、环境基线、攻击面测绘、发现验证、研判去重、报告复测。
- **漏洞利用**：目标确认、前置核验、最小利用链、受控利用、影响边界、清理归档。
- **漏洞修复**：工单分级、隔离复现、根因分析、补丁实施、安全与业务回归、发布关闭。
- **数字孪生攻防**：规则定义、孪生同步校准、攻击注入、检测响应、韧性恢复、状态回放。

## 演示分工

- **左侧流式推理会话**：以逐行生成的可审查推理轨迹呈现范围约束、工具回显、观测关联和当前判断；不展示隐藏思维链，也不放置任务编排卡片。
- **顶部固定干预区**：任务目标和对话干预输入框始终保持可见。输入新的验证重点、优先级或约束后，会同步投影至右侧执行画布。
- **右侧执行画布**：集中显示任务建立、权限边界确认、执行编排、Milestones、靶场/三维数字孪生环境、当前动作和运行记录。
- **自动执行与快进**：任务建立完成后自动逐步运行；可使用“快进至产出”直接结束演示并查看最终产出物。
- **数据管线**：展示长轨迹、运行记录、步骤标注、分支提取、人工质检和数据封装回流。

## 资产空间

资产按两类呈现：

1. **报告产出**：验证记录、根因分析、补丁/评估/复测报告、攻击路径或场景报告。报告采用 Markdown 格式，可在弹窗中预览并下载 `.md` 文件。
2. **数据集产出**：长轨迹与评测数据集、可核验运行记录数据集、回放数据等。可查看 Trace 详情并导出 JSON。

报告弹窗采用安全评估报告的常见结构：执行摘要、范围与交战规则、方法与执行过程、关键发现与证据、风险判断与建议、可追溯性与限制。

## 安全边界

- 所有事件、指标、工具回显和结果均为固定演示数据或仿真执行。
- 所有任务限定在授权、隔离、可回滚的靶场或数字孪生环境。
- 禁止真实网络、真实账号、生产凭据、持久化和无约束破坏动作。
- 最小权限、允许动作、停止条件和留痕要求均在任务建立阶段确认并冻结。
- 页面只展示可审查推理轨迹、工具结果、观测和决策依据，不展示隐藏思维链。

## 本地运行

无需安装依赖：

```bash
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

## 推荐演示操作

1. 首页选择任一典型任务，点击“启动演示任务”。
2. 在左侧阅读 LLM 推理流，右侧查看任务建立、权限边界确认和执行编排。
3. 演示中可在顶部固定输入框发送干预；在执行画布确认其投影。
4. 若需要快速展示结果，点击“快进至产出”。
5. 数字孪生任务中点击三维生产环境节点，查看资产状态和遥测信息。
6. 从产出物卡片或资产空间打开报告 / Trace 详情；报告下载为 Markdown，数据集下载为 JSON。
