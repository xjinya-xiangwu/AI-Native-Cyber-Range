# AI-Native-Cyber-Range · V1.4 前沿版领导演示

本版本从 GitHub 历史提交 `4e3ef1f`（2026-08-13）作为代码基线重写，按 V1.4 PRD 构建一个**唯一面向领导**的 AI-native 安全攻防演示原型。

## 唯一主线

**任务意图理解 → 智能体计划 → 受控执行 → 数字孪生反馈 → 数据生产 → 决策结论**

## 五个页面

1. 领导驾驶舱
2. AI 任务对话
3. Agent 执行工作台
4. 数据生产中枢
5. 决策报告

## 演示边界

- 所有指标、事件、工具回显、环境状态与结果均来自本地固定场景包，明确标识为“演示数据 / 仿真执行”。
- 不包含账号体系、多租户、真实模型或 Agent 接入、真实攻击调度、生产训练平台、报告签发和运维后台。
- 不展示或存储隐藏思维链；仅展示用户可见的计划摘要、执行解释、证据和决策依据。
- 所有安全任务限定于模拟的数字孪生靶场，无真实凭据、生产地址或开放互联网攻击能力。

## 本地运行

无需构建依赖：

```bash
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。断网状态下可完整运行。

## 推荐演示路径

1. 驾驶舱选择“云原生自主运维 Agent 风险评估”。
2. 在 AI 任务对话中确认风险优先级、样本规模、方案与隔离边界。
3. 启动工作台，在策略风险闸门选择“保持隔离验证”。
4. 在证据冲突时选择“替代工具验证”，观看重规划分支。
5. 进入数据生产中枢查看六阶段回流和数据血缘。
6. 在决策报告切换能力、风险、投入视角。
