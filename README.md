# AI-Native-Cyber-Range · 前沿版演示

这是面向领导演示的 AI-native 安全攻防原型。新版参考“对话入口 → Agent 执行流 → 右侧工作空间 → 资产沉淀”的产品动线，把原来分散在多个页面的能力收敛为一条连续故事。

## 演示主线

**一句目标 → Agent 创建任务 → 安全策略冻结 → 受控执行 → 人工干预与重规划 → 数据生产管线 → 决策结论**

## 核心体验

- 首页用自然语言或预置场景启动任务。
- 任务会话明确展示 Agent 如何解析意图、加载安全边界、匹配场景并创建任务快照。
- 执行过程在同一页面连续展示计划、工具调用、环境反馈、风险闸门、人工干预和失败恢复。
- 右侧工作空间同步呈现任务卡、执行画布、数字孪生、六阶段数据生产管线和一页决策结论。
- 资产空间展示由同一任务沉淀的轨迹、证据、标注与训练评测数据包。

## 演示边界

- 所有指标、事件、工具回显、环境状态与结果均为固定演示数据或仿真执行。
- 所有安全任务限定在隔离数字孪生靶场，不包含真实攻击调度、真实凭据或生产地址。
- 仅展示用户可见的计划摘要、工具结果、证据和决策依据，不展示隐藏思维链。

## 本地运行

无需安装依赖：

```bash
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

## 推荐演示操作

1. 在首页选择“云原生自主运维 Agent”，点击“开始创建”。
2. 确认样本规模与时间预算，观看 Agent 创建任务的四个步骤。
3. 点击“启动仿真执行”，观察任务计划、工具调用和数字孪生状态同步变化。
4. 在风险闸门选择“保持隔离验证”，在证据冲突时选择“切换替代工具”。
5. 任务完成后查看六阶段数据生产管线、资产空间和决策结论。
