# AI-Native-Cyber-Range · 前沿版演示

面向安全研究与领导演示的 AI-native 网络安全任务原型。新版把产品动线收敛为：

**任务会话 → 执行画布 / 数据管线 → 产出物卡片 → 资产空间**

## 四类典型任务

- **漏洞挖掘**：授权定界、环境基线、攻击面测绘、发现验证、研判去重、报告复测。
- **漏洞利用**：目标确认、前置核验、最小利用链、受控利用、影响边界、清理归档。
- **漏洞修复**：工单分级、隔离复现、根因分析、补丁实施、安全与业务回归、发布关闭。
- **数字孪生攻防**：规则定义、孪生同步校准、攻击注入、检测响应、韧性恢复、状态回放。

## 工作空间

只保留两个并列子页签：

1. **执行画布**：统一承载任务事实、任务拆分、Milestones、靶场拓扑、当前动作、工具调用、环境状态、人工闸门与运行记录。
2. **数据管线**：模拟长轨迹和 Trace 数据的采集、规整、步骤标注、失败分支提取、人工质检及数据封装回流。

“决策结论”不再作为独立页签。任务最终产出统一展示在任务会话末尾的产出物卡片，并同步到左侧抽屉式资产空间。

## 安全边界

- 所有事件、指标、工具回显和结果均为固定演示数据或仿真执行。
- 所有任务限定在授权、隔离、可回滚的靶场或数字孪生环境。
- 禁止真实网络、真实账号、生产凭据、持久化和无约束破坏动作。
- 高风险、越界、证据冲突和可能影响业务状态的动作必须进入人工闸门。
- 页面展示计划摘要、工具结果、观测和决策依据，不展示隐藏思维链。

## 本地运行

无需安装依赖：

```bash
python -m http.server 8765
```

访问 `http://127.0.0.1:8765/`。

## 推荐演示操作

1. 首页切换四类典型任务，观察任务描述与专业流程变化。
2. 点击“开始编排”，确认范围、样本和时间预算。
3. 冻结交战规则，观看 Agent 创建任务与环境检查点。
4. 启动受控执行，在人工闸门选择继续或非侵入式验证。
5. 在执行画布观察 Milestones、拓扑、工具动作和运行记录联动。
6. 切换数据管线查看长轨迹、Trace 样例与数据血缘。
7. 任务完成后，在会话末尾查看产出物卡片，并从左侧资产空间统一访问。
